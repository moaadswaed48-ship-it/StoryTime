## 3. Decisions

1. **"fører" replaced by "vise vej" / "vejviser" (C07).** "Fører" is correct Danish for a leader, but "Tak, fører"
   and "Du var en god fører" can call up "Føreren" for an adult reader. "Vise vej" matches the book title *Noah
   viser vej* and is what a Danish child says.
2. **C07 adult = "moster"** (mother's sister), which matches the Arabic خالته. "Kusinen" stays.
3. **Kept on purpose:** *Sneglerunden* (C02; it is the fast jumper's own idea and everybody agrees, so it reads as
   affectionate, not mocking); *Langben* (C10; Goofy is "Fedtmule" in Danish, so no clash); "Fem ad gangen" (C10);
   "Det er på tide du hilser på uret" (C11, a light pun); "Lige op er hel. Lige ned er halv."; "juice" in C15 (now
   standard Danish for pressed fruit juice; "saft" is a cordial and would spoil the story's point); "pulterkammer",
   "ovnrens", "giftlinje"; "dæk" for the raft's floor (C14); "Frugtpause!", "Næste gang giver vi", "Flot regnet ud"
   (C05); "havregryn" (C03, the Danish cold breakfast); the chant "Taske, flaske, jakke, hue" (C03); "lyder lysest"
   (C06, avoids "højest" = loudest); "Klask", "Svup … bump … hop", "Fiiiii!".
4. **Comma rule:** no start comma, as in the pilot; a comma always closes a subordinate clause before the main verb,
   and non-restrictive relative clauses take one (C08).
