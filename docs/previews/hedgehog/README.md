# "Where Is Little Hedgehog?" 30-second test film (quick version, 27 Nov 2026)

- Made by the "Ultracode" run of the film test (9 Fable 5.2 helpers, about 5 hours of model time, 3.1 M tokens).
- Drawn in code with Blender Cycles on the CPU at 640x360, preview quality: about 3-6 s per picture, 57 minutes
  for all 732 pictures. The full-quality 1280x720 version (about 30 s per picture, 5-6 hours) was stopped by the owner.
- Sound made in code, no voice. 30.0 s, 6.5 MB.
- The other five effort levels were not run (owner stopped the test). Faster routes: docs/research/faster-films-26nov.md.
