# Version B (optional polish layer)

`version-b.patch` is the interaction and typography polish made with Emil Kowalski's design-engineering
principles and the Impeccable skill, kept apart from the main build so the owner can compare the two.

- Live comparison: version A is the site itself; version B is the same site under `/b/`.
- To adopt B: `git apply docs/versions/version-b.patch`, run the checks, publish.
- To drop B: delete this folder and the `b/` folder on the `gh-pages` branch.
